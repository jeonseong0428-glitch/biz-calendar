# 사업팀 달력

사업팀 업무 일정을 **월간·주간·일간**으로 보는 달력입니다.
**링크만 있으면 누구나 보기·추가·수정·삭제**할 수 있고, 모든 팀원에게 20초 안에 반영됩니다.

- 사이트: https://jeonseong0428-glitch.github.io/biz-calendar/
- 저장 위치: 구글 시트 「사업팀 달력 데이터」 (Apps Script 「사업팀 달력 저장 서버」가 읽고 씀)

| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 달력 화면과 동작 |
| `config.js` | 저장 서버 주소 |
| `apps-script/Code.gs` | 구글 저장 서버 코드 (Apps Script에 붙여 넣어 배포한 원본) |
| `data/events.json` | 처음 넣은 노션 일정 185건 (저장 서버가 시트를 처음 채울 때 사용) |

## 알아둘 점
- 링크를 아는 사람은 누구나 수정할 수 있습니다. 팀 안에서만 공유하세요.
- 시트에서 직접 고쳐도 달력에 반영됩니다. 1행(제목 줄)과 id 열은 건드리지 마세요.
- 저장 서버 코드를 고치면 Apps Script에서 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 단축키
`←` `→` 이전/다음 · `t` 오늘 · `m` `w` `d` 월간/주간/일간 · `n` 새 일정
